# Тихий дом (Hushwood) 12.0 — проект Xcode

## Как поставить на iPhone
1. Открой `Hushwood.xcodeproj` в Xcode (15 или новее).
2. Слева выбери проект **Hushwood** → вкладка **Signing & Capabilities**.
3. В поле **Team** выбери свой Apple ID (если его нет — Add Account; подойдёт бесплатный).
4. В **Bundle Identifier** замени `com.yourname.hushwood` на что-то своё, например `com.ivan.hushwood`.
5. Подключи iPhone кабелем, выбери его сверху в списке устройств и нажми ▶ (Run).
6. На iPhone при первом запуске:
   - Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить (телефон перезагрузится);
   - Настройки → Основные → **VPN и управление устройством** → доверять своему Apple ID.

С бесплатным Apple ID приложение работает 7 дней, потом просто снова нажми ▶ в Xcode.

## Если на каком-то iPhone чёрный экран
Теперь игра сама пишет, что случилось:
- на экране появится текст ошибки (красная плашка или надпись по центру);
- в Xcode внизу, в консоли, строки начинаются с `[Тихий дом]`.
Если система выгружает игру из-за памяти, она сама перезапустится с низкой графикой.
Проверь ещё «Режим блокировки» (Настройки → Конфиденциальность и безопасность) — он отключает 3D-графику в приложениях.
В игре: Настройки → Графика → «Низкая» для слабых устройств.

## «Thread 1: signal SIGKILL» на iPhone с 8 ГБ
Это сообщение Xcode значит: iOS сама закрыла приложение, потому что ему не хватило ресурсов. Под отладчиком Xcode игра получает меньше запаса памяти, поэтому падает чаще.
1. После установки из Xcode нажми ■ Stop, закрой Xcode-запуск и открой игру **с иконки на рабочем столе** — так iOS даёт больше памяти.
2. В 4.0 игра стала легче: нет рельефных карт у текстур (они и мерцали), всего 3–4 источника света вместо двадцати, у врагов нет своих ламп.
3. Если запуск оборвался, следующий запуск сам включит низкую графику и скажет об этом. Вернуть можно в Настройках.

## Игра по сети (до 4 игроков)

### По интернету
1. «По сети» → «Подключение: Интернет».
2. Один нажимает «Создать игру», остальные — «Найти игру» и «Войти к …».
3. Хозяин жмёт «Начать». Игроки могут быть в разных городах и сетях.
4. Сервер только сводит игроков и пересылает пакеты. Мир, монстров и предметы считает хозяин.
   Адрес: `wss://klyrosm.ru/ws?game=hushwood`.

### Рядом по Wi-Fi
1. Поставь приложение на все iPhone (каждому — тот же проект, свой Apple ID можно не менять).
2. Все телефоны — в одной сети Wi-Fi (или просто рядом: работает и напрямую без роутера).
3. При первом входе в «По сети» iPhone спросит доступ к локальной сети — нажми «Разрешить».
   Если случайно запретил: Настройки → Конфиденциальность и безопасность → Локальная сеть → Тихий дом.
4. Выбери «Подключение: Рядом», один нажимает «Создать игру», остальные — «Найти игру» и «Войти к …».
   Хозяин жмёт «Начать».

Предметы, двери и побеги общие. Поймали одного — новый день у всех. Сбежали одним путём — спасены все.
Сложность выбирает хозяин в главном меню.

## Android

В папке `android/` лежит Android Studio-проект 12.0 и готовый APK:

- `android/Hushwood-12.0-android.apk` — установить на Android 7.0+ (разрешить неизвестные источники);
- `android/` — исходники WebView-обёртки, игра в `android/app/src/main/assets/Game/index.html`;
- сборка: открыть папку в Android Studio или `gradle assembleDebug`.

Онлайн-режим работает через тот же сервер, что и на iOS:
`wss://klyrosm.ru/ws?game=hushwood`.

## Управление
- Левая половина экрана — ходьба (джойстик до края — бег), правая — обзор.
- Большая кнопка — действие (взять / открыть / спрятаться / установить).
- Бросить, Положить, Присесть, Фонарь, пауза (II) — там же подсказки и настройки (чувствительность, громкость, голоса, графика).
- Когда найдёшь оружие, появится кнопка выстрела.

## Секрет
В подвале есть тайная комната. Найди шестерёнку для механизма у стеллажа. Внутри — рогатка и запертый сундук. Ключик от сундука спрятан в одном из обитателей дома.

## Спидран
Таймер идёт с первого кадра дня 1 до финального побега, включая поимки.
В конце — сплиты и рекорд для каждой сложности. Максимальная — **Кошмар**:
3 дня, предметы каждый раз в случайных местах, выносливость, садящийся фонарь,
враги быстрее и слышат дальше, предметы не подсвечиваются.

## Если захотите менять игру
Исходники в `game-source/src` (JavaScript + three.js). Сборка:
```
cd game-source
npm install
npm run build
```
Команда пересоберёт `Hushwood/Game/index.html`, дальше снова ▶ в Xcode.
